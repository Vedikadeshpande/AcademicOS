# 🎓 AcademicOS

**AcademicOS** is an AI-powered academic workspace designed to help students manage their entire academic workflow in one centralized place.

The idea started from a simple observation: **students don’t lack tools, they lack a unified system.** Managing coursework usually involves constantly switching between different apps, tabs, notes, calendars, and PDFs. AcademicOS serves as an "Academic Operating System" focused on organization, productivity, and intelligent academic assistance.

## ✨ Current Features (V1)

- **📊 Dashboard & Analytics:** Track academic performance, workload, and study progress through a centralized dashboard.
- **📚 Subject Workspaces:** Organize syllabus content, notes, assignments, and study materials by specific subjects.
- **🧠 Flashcards & Quizzes:** Built-in active recall and quiz generation, along with mock question paper generation systems for more effective revision.
- **📅 Study Planner:** Automatically generate study schedules and organize academic workloads. *(Upcoming updates will focus on smarter prioritization and adaptive planning.)*

## 🛠️ Tech Stack

### Frontend
- **Framework:** React + Vite
- **Routing:** React Router DOM
- **Animations:** Framer Motion
- **Styling:** Tailwind CSS

### Backend & AI
- **Framework:** FastAPI (Python)
- **AI Integration:** Groq / LLM Integration (for quizzes, flashcards, and mock papers)

## 🗺️ Planned Future Updates

One of the core philosophies of AcademicOS is adaptive planning. Currently, scheduling systems treat topics equally, but a smart system needs to account for topic difficulty, confidence level, exam proximity, and actual learning progress.

Upcoming features include:
- **Smarter Topic Prioritization:** Weighted scheduling based on exam dates and difficulty.
- **Completion Tracking:** Topic completion tracking and visual progress bars.
- **Weakness Identification:** Identifying weak topics automatically using quiz and flashcard performance.
- **Dynamic Restructuring:** Dynamic schedule restructuring based on real-time progress.
- **Conversational AI Chatbot:** Integration for flexible, natural language schedule adjustments.
- **Integrated Document Viewing:** In-app PDF and presentation viewing so students can access notes, slides, and study materials directly inside AcademicOS without constantly switching between tabs or downloading files.

The long-term goal is to make the system adaptive to real student behavior, allowing users to reorganize workloads naturally without making productivity feel overwhelming or rigid.
